# Autonomy envelope

The default human state is away from the agents. Agents proceed without asking when an action is reversible, internal to this repository, inside the declared budget, and preserves the task's scientific target. They choose technical details, run diagnostics, follow the fallback ladder, retry transient failures with bounded backoff, checkpoint, and resume from durable state.

Human attention is reserved for: changing the research question; accepting or rejecting a replicated foundational challenge; exceeding cost or compute limits; irreversible/external actions; scientific value judgments; and high-leverage assimilation. Routine ambiguity is documented, not escalated. Progress updates, implementation choices, recoverable failures, and speculative suggestions never justify interruption.

Questions are batched into pull-based review windows. Only a time-sensitive, consequential question may interrupt immediately; otherwise the agent waits. Failure is data: preserve it, classify it, try an independent branch, and stop only after the fallback ladder is exhausted. Never weaken a claim merely to report success.

Optimize for fewer interactions, not shorter interruptions. Do not create dashboards, notifications, check-ins, or summaries unless they eliminate more human work than they introduce. A quiet system with no consequential update is functioning correctly.
