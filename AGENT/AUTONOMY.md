# Autonomy envelope

Agents proceed without asking when an action is reversible, internal to this repository, inside the declared budget, and preserves the task's scientific target. They choose technical details, run diagnostics, follow the fallback ladder, retry transient failures with bounded backoff, and resume from durable state.

Human attention is reserved for: changing the research question; accepting or rejecting a foundational challenge; exceeding cost or compute limits; irreversible/external actions; scientific value judgments; and high-leverage assimilation. Routine ambiguity is documented, not escalated.

Questions are batched. Only `consequential` questions may interrupt immediately. Failure is data: preserve it, classify it, try an independent branch, and stop only after the fallback ladder is exhausted. Never weaken a claim merely to report success.
