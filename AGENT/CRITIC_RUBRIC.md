# Critic rubric

Answer each in writing. "Yes/no" is not an answer; show where.

1. State the claim precisely as the evidence supports it. Is it narrower than the claim in SPEC? Where exactly?
2. What is the severest test that was *not* run? Why not?
3. Which assumption is doing the most work? What happens to the result if it is weakened by one notch?
4. Find the weakest step. Try to construct a counterexample to it. Report the attempt even if it fails.
5. Is any step a [GAP] dressed as a step? Quote it.
6. Does the result contradict anything in SHARED/DEAD_ENDS.md or SHARED/LITERATURE.md? If it agrees with everything, is that suspicious?
7. For experiments: could the result be an artifact of seed, scale, metric choice, or data leakage? What was done to rule each out?
8. For proofs: was any hypothesis added during the proof? Is it natural or convenient (Lakatos)? Is the Lean statement the same as the prose statement?
9. Would a hostile referee in this subfield accept this? Write their first objection.
10. Is the programme progressive or degenerating on the evidence of this task?
Verdict: one of  ACCEPT / ACCEPT-WITH-GAPS / REJECT, with the single most important reason.
